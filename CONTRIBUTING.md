# Contributing

Thanks for helping with `mediastream-upload`.

## Setup

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## Commits

Use [Conventional Commits](https://www.conventionalcommits.org/) — `type(scope): subject`.

## Changesets

For user-facing changes, run `pnpm changeset` and commit the generated file. Maintainers handle publish.
