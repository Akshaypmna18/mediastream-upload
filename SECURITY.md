# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
| 0.1.x   | Best-effort |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Prefer [GitHub private vulnerability reporting](https://github.com/akshaypmna18/mediastream-upload/security/advisories/new)
for this repository.

We aim to acknowledge reports within 72 hours.
